# Corresponding source

For a `pyurd` wheel, download
`pyurd-<VERSION>-corresponding-source.tar.gz` from the matching
[`v<VERSION>` GitHub release](https://github.com/planning-and-learning/urd/releases).
It contains urd's source, build scripts, and patches together with the
exact upstream native dependency sources, including required Git submodules.
The matching urd-only source distribution is also available from the
[PyPI files page](https://pypi.org/project/pyurd/#files).

[`SOURCES.json`](SOURCES.json) is the canonical, machine-readable manifest of
the repositories, revisions, archive URLs, and checksums used to build those
dependencies.
